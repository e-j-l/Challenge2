GitHub Repo Creator

A desktop GUI application that converts a local project folder into a Git repository and publishes it to GitHub, no command line required.

Requirements

  • Java JDK 11 or higher
  • Git installed on your machine
  • GitSubprocessClient (latest version) download here
  • GitHubApiClient (latest version) download here
  • A GitHub account

Setup

  1. Download the GitSubprocessClient and GitHubApiClient .jar files from their GitHub repos under Releases and add them to your project locally.
  2. Run the application via Main.java in your IDE.

Usage

  1. Click Select Folder and choose your local project folder.
  2. Enter a repository name, description, and choose public or private visibility.
  3. Click Create Repository.
  4. The output area will display your new GitHub repository URL when complete.
